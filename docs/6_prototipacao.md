# Prototipação em Papel

A prototipação em papel é uma técnica de baixa fidelidade que permite testar conceitos de interface de forma rápida e barata antes de iniciar o desenvolvimento digital.

## Protótipos Iniciais (Baixa Fidelidade)

Os protótipos iniciais focaram na disposição dos elementos de feedback para o aluno e na estrutura do dashboard estratégico para o professor. Abaixo estão as representações das ideias iniciais que foram validadas com os usuários.

### Esboço 1: Input de Respostas e Feedback
**Objetivo:** Validar se o aluno entende a comparação lado a lado.
(Nesta fase, testamos a disposição do enunciado acima do campo de texto e o feedback aparecendo logo abaixo após a submissão).

### Esboço 2: Dashboard do Professor
**Objetivo:** Validar a utilidade do Mapa de Calor.
(Testamos diferentes formas de representar o erro por questão, optando pelas cores 'quentes' para indicar maior volume de falhas).
